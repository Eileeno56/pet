# Ramas del repositorio pet

Cada rama conserva una línea de trabajo; no representa una sección distinta de la aplicación instalada. El código integrado se encuentra en main.

| Rama | Función |
| --- | --- |
| main | Código integrado que sirve de base a las entregas publicadas. |
| fix/profile-pets-admin | Integración inicial del módulo administrativo y validación de perfiles y mascotas. |
| codex/tester-feedback-beta2 | Correcciones de Iker y Juan José: presentación centrada, fondo, horarios, alimentación, historial, ficha médica y cuidado compartido. |
| codex/evaluation-evidence | Evidencias para la revisión docente y referencias a los reportes de testers; integrada mediante PR #6. |
| codex/email-code-verification | Confirmación obligatoria del correo. Aunque el nombre conserva el enfoque inicial de códigos, el cambio final usa un enlace de Firebase en Spark; integrada mediante PR #7. |
| codex/password-strength-pet-names | Registro desde 8 caracteres, indicador de seguridad y nombres únicos de mascotas por espacio; entrega beta.4, issue #9. |

La última fila solo cuenta como rama remota cuando aparece en [las ramas publicadas](https://github.com/Eileeno56/pet/branches). Las ramas integradas se conservan como evidencia del trabajo.
